# Understanding cycling route choice behaviour through street-level images and discrete choice models
Code and data to reproduce the paper submitted to Transportation Research Part A: Policy and Practice. A preprint of the paper is available [here](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5473360) (not been peer 
reviewed yet).

This study examines cyclist route choice behaviour using a stated choice experiment with over six thousand real-world street-level images from cyclists perspective, analysing preferences for cycling infrastructure and environment. We apply traditional discrete choice models and a recently proposed computer vision–enriched approach (see [paper](https://www.sciencedirect.com/science/article/pii/S0965856424003483?via%3Dihub)) to map alignment between Rotterdam's cycling network and cyclist preferences, and to evaluate the prospective effectiveness of infrastructure upgrades.

## Data
The data file .... contains data from a stated choice experiment. In the experiment, respondents were presented two cycling routes, and were asked to indicate which route they would choose.
