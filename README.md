# Understanding cycling route choice behaviour through street-level images and discrete choice models

Code and data to reproduce the analyses from the paper submitted to Transportation Research Part A: Policy and Practice. A preprint is available [here](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5473360) (not peer reviewed yet).

The study examines cyclist route choice behaviour using an image-based stated choice experiment with over six thousand real-world street-level images from a cyclist's perspective. In this way we analyse cyclist's preferences for cycling infrastructure and environment. We apply traditional discrete choice models and a recently proposed computer vision–enriched approach (see [paper](https://www.sciencedirect.com/science/article/pii/S0965856424003483?via%3Dihub)) to identify where Rotterdam's cycling network (our case study) aligns — or conflicts — with cyclist preferences, and to evaluate the prospective effectiveness of infrastructure upgrades.

## Data
The data file `...` contains responses from a stated choice experiment in which respondents were presented with two cycling routes and asked to indicate which they would choose. Each alternative is described by travel time (TT), number of traffic lights (TC), and a street-level image representing the cycling environment.
